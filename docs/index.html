What it isCe que c'est這是什麼

OSINT — open source intelligence — is research carried out from publicly available sources. The tools that support it are scattered across hundreds of bookmark pages, gists and wikis. OSINT-index collects them into a single versioned catalogue and wraps it in a native app, so finding the right resource is a search box away rather than an afternoon of link-chasing. It is an index of public references for researchers, journalists and students: it points to tools, it does not run them.L'OSINT — renseignement en sources ouvertes — est une recherche menée à partir de sources accessibles au public. Les outils qui la servent sont éparpillés sur des centaines de pages de favoris, de gists et de wikis. OSINT-index les rassemble dans un catalogue unique et versionné, enveloppé dans une app native : trouver la bonne ressource tient dans un champ de recherche plutôt que dans un après-midi à courir après des liens. C'est un index de références publiques pour chercheurs, journalistes et étudiants : il pointe vers des outils, il ne les exécute pas.OSINT——開源情報——是根據公開可得的來源所進行的研究。支援這類研究的工具散落在數百個書籤頁、gist 與 wiki 之中。OSINT-index 把它們彙整成一份有版本管理的目錄，並包裝成原生 App，讓你只需一個搜尋框就能找到合適的資源，而不必花一整個下午追連結。這是一份為研究人員、記者與學生準備的公開參考索引：它指向工具，但不執行工具。

Everything the app displays comes from a single versioned file, data/osint-tools.json, living in the repository — readable, diffable, and reusable outside the app.Tout ce que l'app affiche provient d'un unique fichier versionné, data/osint-tools.json, qui vit dans le dépôt — lisible, comparable et réutilisable hors de l'app.App 顯示的一切都來自儲存庫中的單一版本化檔案 data/osint-tools.json——可閱讀、可比對差異，也能在 App 之外重複使用。

Origin. The initial import came from osint4all, published under CC0 1.0 (public domain, no attribution required — credited here for transparency). A later pass merged 266 further public links from The Ultimate OSINT Collection; that page carries no stated licence, so those entries are referenced as links rather than republished as content. Full details in NOTICE.md.Origine. L'import initial vient d'osint4all, publié sous CC0 1.0 (domaine public, sans attribution requise — crédité ici par transparence). Un passage ultérieur a fusionné 266 liens publics supplémentaires issus de The Ultimate OSINT Collection ; cette page n'indique aucune licence, ces entrées sont donc référencées comme liens plutôt que republiées comme contenu. Tous les détails dans NOTICE.md.來源。最初的匯入來自 osint4all，以 CC0 1.0 發布（公有領域，無須標示出處——在此註明是為了透明）。之後又合併了來自 The Ultimate OSINT Collection 的 266 個公開連結；該頁面未標示任何授權，因此這些項目僅以連結形式參照，而不轉載其內容。完整說明見 NOTICE.md。

Maintenance. Past the initial import the file is curated by hand in the repo — tools added, links corrected, dead entries removed. A dead-link checker (Scripts/check_dead_links.py) runs over the catalogue and reports what has rotted.Maintenance. Après l'import initial, le fichier est entretenu à la main dans le dépôt — outils ajoutés, liens corrigés, entrées mortes supprimées. Un vérificateur de liens morts (Scripts/check_dead_links.py) parcourt le catalogue et signale ce qui a pourri.維護。初次匯入之後，這個檔案在儲存庫中以人工整理——新增工具、修正連結、移除失效項目。失效連結檢查器（Scripts/check_dead_links.py）會掃過整份目錄，回報哪些已經失效。

Requires Xcode 15+ and XcodeGen.Nécessite Xcode 15+ et XcodeGen.需要 Xcode 15+ 與 XcodeGen。

brew install xcodegen
git clone https://github.com/vincentlauriat/OSINT-index.git
cd OSINT-index
xcodegen generate            # generates OSINTIndex.xcodeproj
open OSINTIndex.xcodeproj    # macOS: scheme OSINTIndex — iOS: scheme OSINTIndexiOS

One SwiftUI codebase drives both platforms: models and services are shared, only the platform-specific pieces (Sparkle on macOS, the navigation chrome) differ. See ARCHITECTURE_EN.md for the layer breakdown.Une seule base de code SwiftUI pilote les deux plateformes : modèles et services sont partagés, seules les pièces propres à chaque plateforme (Sparkle sur macOS, l'habillage de navigation) diffèrent. Voir ARCHITECTURE_EN.md pour le découpage en couches.同一套 SwiftUI 程式碼驅動兩個平台：模型與服務共用，只有平台專屬的部分（macOS 上的 Sparkle、導覽外框）不同。分層說明請見 ARCHITECTURE_EN.md。
